# ELL-Supplementary-material
This document provides supplemental materials for the manuscript entitled ``Cooperative Trajectory Tracking Control of Air Intake Environment Simulation System via Robust Control Barrier Function" by Xin Wang, Xuan Qi, Chao Zhai, Hehong Zhang, Wuqi Gong, and Shiqi Zheng, and it is composed of three parts. The first part discusses the dynamics of temperature and pressure in the air intake environment simulation system , the second part presents the mathematical model of the control valves, and the third part provides simulation results of the valve response comparing the proposed SMCBF-based ADRC method with LADRC.
